- fork

- tags
- historique propre


Exam Git;

Ce projet est une petite application web écrite en Go.
Elle permet d’afficher les informations d’un livre (titre, auteur, année) à partir d’un identifiant.

Le serveur Go démarre sur http://localhost:8080

En fonction de l’ID fourni, le serveur recherche le livre correspondant dans une liste (la data), puis il renvoie une page HTML.
